# Ranch Printer Bridge

جسر خفيف للطباعة المباشرة على جهاز الكاشير. الموقع يرسل أوامر RAW ESC/POS إلى هذا الجسر، والجسر يرسلها إلى طابعة Windows/XPrinter بدون نافذة طباعة.

هذا المسار هو الأسرع لطابعات XPrinter الحرارية، ويقلل تقطيع الطباعة وخروج الورقة قبل اكتمال الفاتورة.

## التشغيل

ثبت Node.js على جهاز الكاشير، ثم افتح PowerShell داخل هذا المجلد وشغل:

```powershell
$env:XPRINTER_NAME='XP-80C'
npm start
```

لو اسم الطابعة مختلف، استبدل `XP-80C` بنفس الاسم الظاهر في Windows Printers. إذا لم تضبط الاسم سيستخدم الجسر الطابعة الافتراضية في Windows.

اترك نافذة PowerShell مفتوحة أثناء العمل.

## إعداد الموقع

افتح لوحة التحكم من نفس جهاز الكاشير:

```text
https://ranch-a.vercel.app/dashboard/settings
```

ثم من إعدادات الطابعات اختر:

```text
Network Bridge
```

واكتب رابط الجسر:

```text
http://127.0.0.1:17878/print
```

## اختبار الاتصال

بعد تشغيل الجسر افتح هذا الرابط على جهاز الكاشير:

```text
http://127.0.0.1:17878/health
```

إذا ظهر `ok: true` فالاتصال المحلي يعمل. بعد ذلك استخدم أزرار الاختبار داخل صفحة إعدادات الطابعة.

## ملاحظات مهمة

- لا تشغل أكثر من نسخة من الجسر على نفس البورت.
- اجعل XPrinter هي الطابعة الافتراضية في Windows أو اضبط `XPRINTER_NAME`.
- استخدم Network Bridge بدل Windows print dialog للطباعة السريعة والصامتة.
- الجسر ينفذ أوامر الطباعة بالترتيب، حتى لو وصلت أكثر من فاتورة في نفس اللحظة.
- الطباعة ترسل كـ job واحد إلى Windows، وليست جلسات متقطعة. أمر الفاتورة يرسل كـ ESC/POS Raster واحد كامل لتقليل التوقفات بين مراحل الطباعة.
- إذا اختفت كلمة Printing من شاشة الطابعة والورقة ما زالت تخرج، فهذا يعني غالباً أن Windows أنهى إرسال المهمة وأن الطابعة تكمل من الذاكرة الداخلية. التوقفات القصيرة أثناء الخروج تحدث عند امتلاء/تفريغ buffer أو ارتفاع حرارة رأس الطباعة.
